### About me

- Third-year **B.Tech student in Artificial Intelligence & Machine Learning** at **Symbiosis Institute of Technology, Pune**.
- I built [Kalaza Care](https://github.com/Anhad23mahajan/kalaza-care), a patient-management Android app for an elder-care NGO in Pune, and I am now improving its companion app, [Kalaza Leads](https://github.com/Anhad23mahajan/kalaza-leads).
- I take part in hackathons with a team of friends. In October 2026 we built [RiskAtlas](https://github.com/AmanS-06/RiskAtlas) for the Multimodal AI Hackathon at IIT Mandi and [Lumen](https://github.com/Eshaan1e24/Lumen) for ForgeHacks Online.
- Most of my machine learning projects started as course work at SIT, and each one has its own repository with a write-up.

### Apps

| Project | What it is | Stack |
|---|---|---|
| [Kalaza Care](https://github.com/Anhad23mahajan/kalaza-care) | Patient-management Android app for an elder-care NGO. Role-based medication tracking, QR-scan administration and real-time escalation alerts. | Kotlin, Jetpack Compose, Supabase, Firebase |
| [Kalaza Leads](https://github.com/Anhad23mahajan/kalaza-leads) | Enquiry-to-conversion CRM for the same NGO, for the families who call to ask about care before they become residents. | Kotlin, Jetpack Compose, Supabase |
| [VaultMind](https://github.com/Anhad23mahajan/vaultmind) | Self-hosted document Q&A using a local LLM, with AES-256-GCM encryption at rest. | Java, Spring Boot, PostgreSQL, Ollama |

### Machine learning and data

| Project | What it is | Stack |
|---|---|---|
| [Hospital Readmission Predictor](https://github.com/Anhad23mahajan/hospital-readmission-predictor) | Full-stack ML web app that predicts 30-day hospital readmission risk, with AI-generated clinical summaries. | Python, Flask, scikit-learn, XGBoost, Docker |
| [Student Performance Prediction](https://github.com/Anhad23mahajan/student-performance-prediction) | Comparison of 11 ML models. Random Forest scored F1 = 0.975 and AUC = 0.995. | Python, scikit-learn, XGBoost, Pandas |
| [Flood Forecasting with CNN-LSTM](https://github.com/Anhad23mahajan/flood-forecasting-cnn-lstm) | Can a neural network forecast how a flood spreads over time? Report, code and results of our Deep Learning project. | Python, TensorFlow, Keras |
| [Poverty Escape Prediction](https://github.com/Anhad23mahajan/poverty-escape-prediction-ihds) | Which Indian households climbed out of poverty between 2004 and 2012, using the IHDS survey. | Python, scikit-learn, XGBoost, SHAP |
| [India Clean Energy Dashboard](https://github.com/Anhad23mahajan/india-clean-energy-dashboard) | Two-view Power BI dashboard on whether India's grid is ready for clean energy. | Power BI |
| [ZeroPlate](https://github.com/Anhad23mahajan/Foundations-of-Agentic-AI-Project) | Multi-agent AI planner that helps a college canteen decide how much to cook. Built with Aman Saxena. | Python, LangGraph, MCP, Ollama, Streamlit |
